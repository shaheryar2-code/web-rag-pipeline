# web-rag-pipeline


A RAG (Retrieval-Augmented Generation) pipeline built with LangChain that loads web content, chunks and embeds it, stores it in ChromaDB, and answers natural language questions using an LLM.


RAG pipeline with LangChain — load a web page, embed it, and ask questions grounded in real content.

With tech stack tags (good for discoverability)

LangChain-based RAG app: web scraping → chunking → HuggingFace embeddings → ChromaDB → Gemini LLM for grounded Q&A.
